# Little Loop Studio

A responsive landing page for a handmade crochet business, built with HTML, CSS and JavaScript.

## Features
- Navbar with working links and a mobile menu
- Hero section with heading, description and button
- About Us, Services and Contact sections
- Contact form with validation and a thank-you message
- Works on mobile and desktop

## How to run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose Open with Live Server, or double-click `index.html` to open it in your browser.

## Pages / Sections
- Home (hero)
- About Us
- Services
- Contact

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (menu toggle, form validation)
