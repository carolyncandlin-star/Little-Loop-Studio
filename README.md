# Little Loop Studio

A responsive interactive landing page for a handmade crochet business, built with HTML, CSS, and JavaScript.

## Features
-Navbar with working links and a mobile menu toggle
-Hero section with interactive auto-playing image carousel and buttons
-About Us, Services (Product Grid), and Contact sections
-Contact form with client-side validation and success/error feedback messages
-Fully responsive layout tested across mobile and desktop devices

## How to run
1.Download or clone this repository.
2.Open the folder in VS Code.
3.Right-click `index.html` and choose Open with Live Server, or double-click `index.html` to open it in your browser.

## Pages / Sections
-Home (hero)
-About Us
-Services (Product Grid)
-Contact

## Technologies Used
-HTML5
-CSS3 (Flexbox, Grid, media queries)
-JavaScript (Mobile menu toggle, form validation, interactive carousel)
